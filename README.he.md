# Web Compliance Prompts — רואים, מתאימים ומתקינים

**ללא CLI, ללא חשבון וללא חבילות תוכנה אצל הלקוח.**

[לפתיחת ההתנסות](https://ward3107.github.io/web-compliance-prompts/) · [הכנת חבילה לאתר](https://ward3107.github.io/web-compliance-prompts/start.html) · [הורדת הסטודיו למחשב](https://ward3107.github.io/web-compliance-prompts/web-compliance-studio.zip) · [חיבור לעוזר קוד](https://ward3107.github.io/web-compliance-prompts/connect.html) · [English](README.md)

כלי בדפדפן לבאנר עוגיות, טיוטות מסמכים ופרומפטים לפיתוח. הבאנר, הממשק ומייצא ה־ZIP בנויים ב־HTML, CSS ו־JavaScript רגילים, **ללא ספריות חיצוניות בזמן השימוש**. אין צורך ב־React, ב־npm, ב־CDN או במפתח API. כלי הבדיקות נמצאים בצד הפיתוח בלבד.

> כל התוצרים הם טיוטות לבדיקה, לא ייעוץ משפטי ולא אישור תאימות. כל שש חבילות המדינה ממתינות לביקורת מקצועית. הבאנר אינו חוסם אוטומטית כלי מעקב שהותקנו באמצעות קוד או תוספים אחרים.

## מתחילים בארבעה צעדים

1. **רואים ומתנסים:** פותחים את התצוגה, מנסים 12 עיצובים וארבע שפות, וקוראים את שלוש טיוטות המסמכים וכל 13 התבניות. אין צורך למסור פרטי עסק.
2. **מתאימים:** עוברים לאשף, ממלאים פרטים ומקבלים תצוגה של הבאנר. העיצוב והשפה שבחרתם עוברים לאשף.
3. **בודקים ומורידים:** מקבלים סיכום, קובץ מותאם והוראות. ההורדה לא משנה דבר באתר.
4. **מתקינים ובודקים:** מעלים תוסף WordPress או מעבירים את החבילה למי שמטפל באתר. בודקים את הבאנר וכלי המעקב, ואת המסמכים מעבירים לביקורת.

הקישור פותח התנסות פעילה מיד, גם בטלפון. בכל שלב באשף כתוב מה עושים עכשיו ולאן ממשיכים. אם חסר פרט, כפתור ההשלמה מחזיר למקום הנכון. לא יודעים באיזו מערכת האתר בנוי? זו אפשרות תקינה, והיא ברירת המחדל.

הממשק המודרך הוא בעברית. הבאנר תומך בעברית, ערבית, אנגלית ורוסית, כולל RTL. מחולל המסמכים מכין טיוטות בעברית עבור פרויקט לישראל בלבד; שינוי שפה אינו מרחיב כיסוי משפטי.

## איזו התקנה מתאימה לכם?

| סוג האתר / השימוש | מה עושים |
|---|---|
| WordPress | מורידים ZIP מותאם → תוספים → תוסף חדש → העלאת תוסף → התקנה והפעלה. נדרשות הרשאות להתקנת תוספים. |
| אתר רגיל או מערכת מותאמת | מעלים ארבעה קבצים לתיקיית האתר ומעתיקים את הקטע שב־`embed.html.txt`. כפתור העדפות נוצר אוטומטית. |
| React / Next.js | המפתח טוען את הקבצים פעם אחת במעטפת הדפדפן ומחבר את כלי המעקב לאירועי ההסכמה. |
| פלטפורמה סגורה | נדרשת אפשרות להוסיף קוד מותאם. אין התקנה אוטומטית אוניברסלית לכל מערכת. |
| עבודה בלי אינטרנט | מורידים את הסטודיו, מחלצים את **כל** הקבצים ופותחים `START-HERE.html` בדפדפן במחשב. אין צורך בשרת מקומי. |
| שימוש בפרומפטים | קוראים את התבניות או מורידים פרומפטים מותאמים מהכלי המתקדם. תוסף לעוזר קוד הוא אפשרות בלבד. |

בחבילה הרגילה פתחו `preview.html` כדי לבדוק את הבאנר לפני העלאה. העלו רק את `cookie-consent.js`, `cookie-consent.css`, `theme.css` ו־`install.js`. אין להעלות את כל חבילת המקורות, קובץ הפרויקט או התיק המשפטי לתיקייה ציבורית.

הבאנר מתחיל ב־opt-in לכל מבקר. מדינות היעד של העסק אינן הוכחה למיקום המבקר. צריך לחבר ולבדוק את כלי המעקב **לפני הפעלתם**, כולל כלים שנטענים בראש העמוד. קטע ההטמעה אינו מסדר אוטומטית את הטעינה של קוד אחר.

להסרה: מחקו את קטע ההטמעה ואת ארבעת הקבצים, או השביתו ומחקו את תוסף WordPress. הפעולה אינה מסירה כלי מעקב אחרים או את בחירות ההסכמה שכבר נשמרו אצל מבקרים.

## מה מקבלים בפועל?

- **באנר עוגיות פעיל:** קבלה, דחייה, העדפות, אותות הסכמה וכיבוד GPC.
- **עיצוב:** 12 אפשרויות, עריכת טקסטים, צבעים, גופן וכפתורים, תצוגה ובדיקת ניגודיות.
- **שלוש טיוטות בעברית:** פרטיות, תנאי שימוש וביטולים/החזרים. פרטים חסרים מסומנים; המסמכים אינם מתפרסמים אוטומטית.
- **13 תבניות:** הבאנר, בסיס נגישות, רכיב נגישות, הצהרת נגישות, פרטיות, תנאי שימוש, החזרים, הבהרות, קופה, דיוור, חוזה פרילנס, שאלון לקוח וזכויות בנושא מידע אישי. יתר הרכיבים הם פרומפטים ליישום, ולא כלים שכבר מותקנים.
- **תיק לעורך דין:** פרטי הפרויקט, שאלות פתוחות, מקורות וטיוטות. ההעברה לעורך הדין נעשית על ידכם בלבד.

אין כרגע סריקת אתר, חסימה אוטומטית של תוספי מעקב, מנויים, חיוב, ניטור או הזמנת עורך דין. אין אישור משפטי או הסמכת נגישות.

## פרטיות ועצמאות

הנתונים נשארים בזיכרון הדפדפן בזמן העבודה; שמרו קובץ פרויקט כדי להמשיך ביום אחר. סגירת עמוד בלי שמירה מאבדת את העבודה. תצוגת הבאנר שומרת רק העדפות הדגמה בנפרד מבחירת ההסכמה הרגילה.

בתוסף ובחבילת ההטמעה אין תשובות לשאלון, כתובת אימייל פרטית או טיוטות משפטיות. קובצי הפרויקט והתיק המשפטי כוללים פרטים: שמרו אותם במקום פרטי. הסטודיו אינו שולח אותם אוטומטית. בגרסה המקוונת ספק האחסון מקבל בקשות רשת רגילות; בגרסה המקומית העריכה וההורדות פועלות בלי אינטרנט, אך קישורים למקורות חיצוניים דורשים חיבור.

אין שירות חיצוני שחייב לפעול כדי שהבאנר באתר שלכם יעבוד. אפשר לאחסן את הקבצים אצלכם. בדיקת SHA-256 של ההורדה זמינה לצד ה־ZIP; היא בודקת התאמה לקובץ שפורסם, ואינה חתימה עצמאית נגד פגיעה בשרת המפיץ.

## אבטחה ובדיקות

נוספו סינון כתובות מסוכנות בתוך הווידג׳ט, טיפול בטקסט כטקסט ולא כקוד, הגבלות ייבוא וייצוא, הגנת נתיבי ZIP, רשימה מפורשת של קבצים ציבוריים, מדיניות CSP וכלי בדיקה לתהליך הפיתוח. הרשאות תהליכי GitHub מצומצמות ופעולות צד שלישי מוצמדות לגרסת commit.

**אין הבטחת ״100% מאובטח״.** נדרשים עדכונים שוטפים, הרשאות נכונות באחסון, הגנות בחשבון GitHub ובדיקת ההטמעה באתר האמיתי. [מדיניות אבטחה וגבולות הבדיקה](SECURITY.md) · [בדיקות גרסה 2.7.0](docs/verification/2.7.0.md) · [בדיקות אוטומטיות](https://github.com/ward3107/web-compliance-prompts/actions).

## חיבור MCP לעוזר קוד — אופציונלי

[פותחים את מדריך החיבור](https://ward3107.github.io/web-compliance-prompts/connect.html), מורידים ומחלצים את החבילה, בוחרים תוכנה ומדביקים את הנתיב לקובץ השרת. הדף מכין הגדרה ל־Claude Code, ל־VS Code או לכלי תואם. אחר כך מבקשים מהעוזר להציג תבניות ולהכין באנר.

נדרש **Node.js 22 ומעלה** בסביבה שבה העוזר פועל, אבל אין ספריות npm להתקנה. השרת משתמש רק בכלים המובנים של Node, קורא קבצים קבועים מהחבילה ומחזיר תוכן. הוא אינו כותב קבצים, מריץ פקודות או פונה לרשת. לעוזר עצמו עשויות להיות הרשאות נוספות, ותוכן עשוי להישלח לספק ה־AI שלו. השימוש הרגיל בדפדפן נשאר עצמאי ואינו דורש MCP.

[הכלים, התאימות והוראות ההסרה](mcp/README.md). אין טענה לחיבור אוטומטי לכל תוכנה; נדרשת תמיכה ב־MCP מקומי דרך stdio.

## למפתחים בלבד

התקנת התוסף ב־Claude Code היא אופציונלית:

```text
/plugin marketplace add ward3107/web-compliance-prompts
/plugin install web-compliance@web-compliance
```

תוסף Claude Code כולל גם את שרת ה־MCP המקומי, ולכן כלי ה־MCP דורשים Node.js 22 ומעלה. אין צורך להגדיר בנוסף חיבור ידני כפול.

למחולל Python, בדיקות ובנייה מקומית: [הוראות הפיתוח המלאות](README.md#development-and-verification). לקוח שמשתמש בדפדפן או ב־ZIP אינו צריך להתקין את כלי הפיתוח.

המקורות כוללים חבילות לישראל, לאיחוד האירופי, לבריטניה, לארה״ב הפדרלית, לקליפורניה ולקנדה. רוב תבניות המסמכים מוגבלות לישראל; שכבת זכויות נושאי מידע דורשת ישראל והאיחוד האירופי יחד. החבילה האמריקאית אינה מכסה כל מדינה בארה״ב.

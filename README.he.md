# Web Compliance Prompts — התחלה מהירה

כלים ליצירת טיוטות והנחיות לבניית באנר עוגיות, דפי מדיניות ותיקוני נגישות. אפשר להשתמש בתוסף של עוזר הקוד, במחולל מקומי או בווידג׳ט העוגיות ישירות.

**הפלט הוא טיוטה לבדיקה, לא ייעוץ משפטי או הבטחת תאימות. כל שש חבילות המדינה עדיין ממתינות לאישור משפטי.**

## התנסות

[דמו חי](https://ward3107.github.io/web-compliance-prompts/) · [הוראות התקנה מלאות](README.md#install) · [תוצאות בדיקות](https://github.com/ward3107/web-compliance-prompts/actions)

בדמו בוחרים שוק ושפה ופותחים את הבאנר. אין בו אנליטיקה או פיקסלים פרסומיים פעילים; הבחירה נשמרת בדפדפן ואפשר לאפס אותה.

## התקנת התוסף

ב־Claude Code:

```text
/plugin marketplace add ward3107/web-compliance-prompts
/plugin install web-compliance@web-compliance
```

לאחר מכן בקשו למשל: ״הכן לי פרומפט לבאנר עוגיות באתר עסקי בעברית, לשוק הישראלי״. מסרו את פרטי העסק ואת הכלים שבאתר בפועל. בקשות בעברית ובערבית מקבלות הנחיות RTL.

## שימוש בפרופיל פרויקט קבוע

מהתיקייה הראשית של עותק הפרויקט:

```text
python -m pip install -r requirements.txt
python scripts/generate.py --describe cookie-banner
```

העתיקו את [פרופיל הדוגמה הישראלי](examples/profiles/israel-he.json) לקובץ `project-profile.json` ועדכנו אותו. פרטי הדוגמה מומצאים ומסומנים ככאלה; אל תפרסמו אותם בשם עסק אמיתי. הקובץ המקומי הזה מוחרג מ־Git כדי שלא יועלה בטעות.

```text
python scripts/generate.py --profile project-profile.json --artifact cookie-banner --output generated/cookie-banner.md --manifest generated/cookie-banner.manifest.json
```

המחולל מחבר את הפרופיל, התבנית והמקורות לחבילות שנבחרו. שדות חסרים או שוק לא נתמך גורמים לשגיאה ברורה. `--allow-missing` מפיק טיוטה שמסומנת כחסרה במפורש. אפשר לקבוע `--date YYYY-MM-DD` כדי לשחזר בדיוק את אותו פלט.

קובץ ה־manifest מכיל גרסאות וגיבובי מקורות, שפה וכיווניות, הנחות, התנגשויות ומצב הבדיקה המשפטית. הוא אינו אישור שהדינים חלים על העסק.

## גבולות הכיסוי

באנר העוגיות, בסיס הנגישות ווידג׳ט הנגישות יכולים לקבל הקשר מכל החבילות הקיימות. תבניות המדיניות, החוזים, ההצהרה, ההחזר, הדיוור, הקופה והשאלון עדיין כוללות ניסוחים ישראליים. המחולל מגביל אותן לישראל ולא מציג אותן כתמיכה משפטית במדינות אחרות. שכבת זכויות נושאי המידע היא תוספת לשילוב ישראל והאיחוד האירופי.

בחירת שפה אינה בחירת דין. אל תשתמשו בחבילה של שוק דומה בתור תחליף לשוק שאין לו חבילה.

## בדיקות והטמעה

```text
python scripts/validate.py
python -m unittest discover -s tests -p "test_*.py"
npm ci --ignore-scripts
npm test
npx playwright install chromium firefox webkit
npm run test:browser
```

הבדיקות מכסות הסכמה, GPC, העדפות שמורות, שינויים באזור, מקלדת, מובייל, ארבע שפות ושלושה מנועי דפדפן. בדיקות רשת משתמשות במעקב מדומה בשרת מקומי, ובדיקות axe הן אוטומטיות. הן אינן בדיקה ידנית בקורא מסך או אישור שהתגים באתר הלקוח חסומים בפועל.

להטמעה ישירה קראו את [מדריך הווידג׳ט](widgets/cookie-consent/README.md). הווידג׳ט מנהל אותות הסכמה; צריך לחבר אליהם את כלי המעקב ולבדוק באתר האמיתי אילו בקשות יוצאות לפני הסכמה ואחרי ביטול.

## התאמה והורדה ללקוחות

[פתחו את ממשק ההתאמה](https://ward3107.github.io/web-compliance-prompts/builder.html): בחרו צבעים, גופן, מיקום ושפה, מלאו את פרטי העסק והורידו ZIP. החבילה כוללת באנר מוכן להתקנה, פרופיל לשימוש חוזר, פרומפטים מותאמים וכל קובצי המקור. הוראות ההתקנה נמצאות ב־START-HERE.md. רכיבי נגישות ומסמכים נוספים הם תבניות ליישום ובדיקה, ולא רכיבים מותקנים או אישור משפטי.

# 2.7.0 verification scope

This release changes the customer journey and adds an optional local stdio MCP server. It retains the [2.6.0 security boundaries](2.6.0.md), conservative opt-in exports and private/public download separation.

## Automated checks

- `npm test`: consent, ZIP, document and MCP regression tests. MCP tests spawn the actual server from an unrelated working directory and check negotiation, initialization state, notifications, malformed UTF-8/JSON, unsupported methods, allowlisted paths, extra fields, unsafe URLs, bounded input, canonical output files and literal user text.
- `python -m unittest discover -s tests -p 'test_*.py'`: generation/workflow, publication allowlist, archive checksums, private-file exclusion and dependency-lock tests.
- `npm run test:experience`: the published homepage and offline studio, preset/language transfer, live rejection/reopening, the 13-template catalog, 320/390/768px layouts, accessibility, CSP enforcement and real universal ZIP downloads. Extracts the MCP ZIP and reruns the server suite against the packaged copy. Also tests Windows-path escaping, portable/VS Code configuration formats, stale configuration invalidation and actual configuration-file downloads.
- `node scripts/test-guided.cjs`: four-step navigation, incomplete fields, unknown answers, contrast, copy editing, review ZIPs, WordPress ZIPs, private-data separation and save/resume.
- `node scripts/test-documents.cjs`, `node scripts/test-builder.cjs`, `npm run test:browser`: document/advanced paths, exported runtime, keyboard/RTL behavior and synthetic tracker checks.
- CI runs Chromium, Firefox and WebKit, the disposable WordPress installation test, dependency audits, validation and gated CodeQL. Pages waits for the exact tested main commit. Check the linked release PR and Actions results for the commit's actual status.

## Boundaries

Automated protocol tests and configuration examples do not establish a live connection in every editor. Claude Code/VS Code configuration follows official documentation; no authenticated editor session is part of the automated suite. The MCP server supports initialized-session revisions through 2025-11-25 and stdio only, not a hosted HTTP connector. Its read-only tools return files as text; the client decides whether to apply them using its own permissions.

Automated accessibility checks are not a manual screen-reader audit. Customer production tracking, host security headers, account security, branch protection, independent penetration testing and legal review remain outside these tests. The previous review's legal status is unchanged. Zero third-party runtime dependencies is not a claim of zero vulnerabilities.

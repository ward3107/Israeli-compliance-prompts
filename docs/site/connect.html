אפשרות למי שעובד עם עוזר קוד

תנו לעוזר שלכם
את הכלים הנכונים.

MCP הוא חיבור שמאפשר לעוזר לקרוא את התבניות שלנו ולהכין קובצי באנר. מתקינים את החיבור פעם אחת, ואז פשוט מבקשים מהעוזר לעזור.

עובד מקומית עם כלי שתומך ב־MCP דרך stdio. נדרש Node.js 22 ומעלה במחשב או בסביבת העוזר; לא נדרשים npm install, חשבון נוסף או מפתח API שלנו. שירות ה־AI שלכם כפוף לתנאים שלו.

אין לכם עוזר קוד? אפשר לעשות הכול באשף הדפדפן ←
שלב 1

מורידים ומחלצים תיקייה

שמרו את התיקייה במיקום קבוע במחשב שבו העוזר פועל. חלצו את כל הקבצים. הקובץ שנחבר נמצא בתוכה: mcp/server.mjs.

הורדת חבילת MCP

ההורדה כוללת את השרת, התבניות וקובצי הבאנר. לא מתבצעת התקנה אוטומטית.

שלב 2

מכינים את הגדרת החיבור

בחרו את התוכנה והדביקו את הנתיב המלא לקובץ שחילצתם. ההגדרה נוצרת כאן בדפדפן.

העתיקו את הנתיב דרך מנהל הקבצים. ב־Windows הוא יכול להיראות כך: C:\Tools\web-compliance-mcp\mcp\server.mjs. בעבודה מרחוק, השתמשו בנתיב בסביבת העוזר.

כבר יש קובץ הגדרות? הוסיפו אליו רק את הרשומה web-compliance. אל תחליפו הגדרות של חיבורים אחרים. בדקו את ההגדרה לפני אישור ההפעלה בתוכנה.


שלב 3
פותחים את העוזר ומבקשים להתחיל
פתחו מחדש את הפרויקט או הפעילו את החיבור דרך הגדרות MCP. ודאו ש־web-compliance מחובר ושמופיעים ארבעה כלים, ואז כתבו:
השתמש ב־web-compliance. קודם הצג לי מה אפשר להכין. שאל אותי על האתר, השפה ומדיניות הפרטיות. אחר כך הכן באנר והצג את השינויים המוצעים לפני שתשנה קבצים באתר. אל תנחש פרטים חסרים.


מה העוזר יכול לעשות?
  • לראות את כל 13 התבניות ו־12 העיצובים.
  • לקרוא תבניות ומקורות לפי מדינה.
  • להכין קובצי באנר ל־WordPress או לאתר אחר.
  • להסביר איך להטמיע ומה לבדוק.
אתם מחליטים מה משתנההשרת שלנו מחזיר תוכן בלבד. הוא לא כותב קבצים, מריץ פקודות, מתקשר לרשת או מתקין באתר. לעוזר הקוד עצמו עשויות להיות הרשאות נוספות. תוכן שתבקשו ממנו עשוי להישלח לספק ה־AI שלכם.
החיבור לא עולה?
  • ודאו ש־Node.js 22 ומעלה מותקן ונגיש לתוכנה. אם לא, התקינו אותו ממקור רשמי ופתחו מחדש את התוכנה.
  • בדקו שהנתיב מוביל לקובץ server.mjs ושכל התיקייה חולצה.
  • אשרו את החיבור בכלי שלכם ובדקו את יומן MCP.
  • לכלי אחר עשוי להיות מבנה הגדרות שונה; השתמשו בערכי command ו־args לפי התיעוד שלו.
